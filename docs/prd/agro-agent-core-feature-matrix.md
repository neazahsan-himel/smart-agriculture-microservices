# Agro Agent — Consolidated PRD Feature Matrix

> Extracted from `agro-agent-core-feature-matrix.xlsx`. Source of truth is the xlsx; this markdown exists so the content is diffable and searchable in git.

**Core Thesis:** কৃষক যেন অনুভব করে—"এই Agent আমাকে চেনে, আমার জমি-পুকুর চেনে, সঠিক সময়ে কী করতে হবে বলে এবং ফল না পাওয়া পর্যন্ত পাশে থাকে।"

## Sheet 1: PRD Feature Matrix

| মূল Feature | Feature + বাস্তবিক Farmer Experience / Implementation | Agent কার্যকারিতা + প্রয়োজনীয় Intelligence/Data + Priority |
|---|---|---|
| Human-like Conversational Onboarding | Traditional signup/form নয়। Farmer app খুলেই full-screen call/video-call style AI Agro Agent দেখবে। Agent greeting দিয়ে নাম/ফোন নম্বর জিজ্ঞেস করবে; farmer voice-এ উত্তর দেবে এবং backend-এ account/profile তৈরি হবে। এরপর জমি, পুকুর, ফসল, farming experience, location ও প্রয়োজনীয় context কথোপকথনের মধ্যেই সংগ্রহ হবে। Farmer-এর কাছে experience হবে—"Agent আগে থেকেই বসে আছে আমাকে সাহায্য করার জন্য"; system configuration বা form filling তার দায়িত্ব না। | Agent voice conversation থেকে identity ও farm information extract করে structured profile বানাবে, missing information smartভাবে জিজ্ঞেস করবে এবং onboarding state manage করবে। দরকার: Bangla Speech-to-Text, Text-to-Speech, Conversational AI, Entity Extraction, Profile Builder, Identity/OTP layer; future Gov deployment-এ consent-based NID/face verification। Priority: MVP Core. |
| Farmer Identity & Trust Profile | প্রতিটি farmer-এর শুধু user account নয়, একটি persistent identity/context থাকবে—নাম, বয়স, farming experience, location, preferred language/dialect, skill level, decision style, household dependency, farm size ও risk tolerance। ফলে ২০ বছরের experienced farmer এবং নতুন farmer একই ধরনের generic advice পাবে না। | Agent farmer-এর communication ও decision history থেকে personalization করবে এবং advice-এর depth/ভাষা adjust করবে। দরকার: Persistent User Memory, Preference Learning, User Skill Model, Trust/Profile Graph, consent-aware identity data। Priority: MVP. |
| Farm Digital Memory / Farm Brain | প্রতিটি জমি, পুকুর, ফসল ও season-এর living digital history থাকবে। গত বছর কোন crop হয়েছিল, কী রোগ হয়েছিল, কী treatment দেওয়া হয়েছিল, কোন input কতবার ব্যবহার হয়েছে, ফলন/খরচ/বিক্রি/সমস্যার outcome কী ছিল—সব future decision-এর context হবে। Farmer যেন অনুভব করে: "এই Agent আমার ক্ষেত চেনে।" | Agent current problem-এর সাথে previous season, treatment ও outcome compare করবে; relevant history নিজে retrieve করবে এবং future recommendation-এ ব্যবহার করবে। দরকার: Long-term Memory, Structured Farm Records, Semantic Retrieval, Time-series/Event History, Outcome Store। Priority: MVP Core. |
| Farm Asset Management | Farmer-এর প্রতিটি farm asset আলাদা profile হবে—যেমন Rice Plot 1, Rice Plot 2, Eggplant Field, Tilapia Pond, Mixed Fish Pond। প্রতিটির location, area, crop/fish type, stage, soil/water condition, history, task ও risk আলাদা থাকবে। UX-এ farmer শুধু "আমার জমি / আমার পুকুর / আমার বাগান" দেখবে; technical configuration hidden থাকবে। | Agent প্রতিটি asset-এর current state ও history আলাদাভাবে track করবে এবং advice asset-specific রাখবে। দরকার: Farm Asset Graph, GIS/Geo-tag, Plot/Pond Records, Crop-stage/Stock-stage model, spatial context। Priority: MVP. |
| Master Agent + Specialist Agents | একজন overall Agro Agent farmer-এর পুরো farm portfolio বুঝবে, কিন্তু প্রয়োজন হলে প্রতিটি জমি/পুকুরের জন্য specialist context-agent কাজ করবে। Farmer ১০টা জমি ও ৫টা পুকুর manage করলেও তাকে বহু AI manage করতে হবে না; Master Agent সব specialist insight একত্র করবে। | Master Agent query/context routing করবে; Rice, Vegetable, Pond বা Market specialist intelligence থেকে answer নিয়ে cross-asset decision দেবে। দরকার: Multi-Agent Orchestration, Shared Memory, Context Routing, Specialist Domain Models, conflict resolution। Priority: MVP / Phase 2. |
| Voice-First Agricultural Assistant | Text-heavy UI নয়। Farmer স্বাভাবিক ভাষায় বলবে: "আমার বেগুনের ডগা শুকাইতেছে", "পুকুরের মাছ ভোরে উপরে উঠতেছে"—Agent কথা শুনে follow-up question করবে এবং voice-এ guidance দেবে। পড়তে কম জানেন বা ছোট ফোন ব্যবহার করেন—তাদেরও app usable থাকবে। | Agent speech বুঝবে, ambiguity detect করবে, context ধরে relevant প্রশ্ন করবে এবং সংক্ষিপ্ত spoken action দেবে। দরকার: Bangla ASR, dialect-tolerant NLU, conversational reasoning, TTS, noise handling, low-bandwidth voice flow। Priority: MVP Core. |
| Local Language & Dialect Adaptation | Standard Bangla-তে সীমাবদ্ধ নয়। Farmer যে অঞ্চলের ভাষায় কথা বলে, Agent ধীরে ধীরে সেই শব্দ/উচ্চারণ ও conversational style বুঝবে। Technical term সহজ familiar ভাষায় explain করবে। | Agent dialect mapping ও personal vocabulary memory ব্যবহার করবে; unclear শব্দে confirmation নেবে। দরকার: Dialect NLP, Language Adaptation, Personal Lexicon, Simplification Engine। Priority: Phase 2. |
| Image-based Crop Diagnosis | Farmer leaf, fruit, stem, root বা পুরো গাছের ছবি দিয়ে problem দেখাতে পারবে। Agent শুধু একটা ছবি দেখে blind diagnosis না দিয়ে দরকার হলে close-up, healthy comparison বা field-wide photo চাইবে। | Agent visual symptom detect করে disease, pest, nutrient deficiency বা physiological disorder-এর differential diagnosis তৈরি করবে; confidence অনুযায়ী next step দেবে। দরকার: Computer Vision, Plant Pathology, Agronomy, Visual Retrieval, Confidence Scoring। Priority: MVP Core. |
| Video-based Farm Observation | Short video দিয়ে পুরো field pattern, fish behaviour, pond surface, water colour, plant distribution বা movement-based সমস্যা capture করা যাবে। বিশেষ করে pond ও spread pattern-এর জন্য video static image-এর চেয়ে বেশি useful হবে। | Agent video থেকে temporal/behavioural cues detect করবে এবং প্রয়োজনমতো frame/condition compare করবে। দরকার: Video Understanding, Computer Vision, Fish Behaviour/Aquaculture Knowledge, temporal pattern detection। Priority: Phase 2. |
| Smart Diagnostic Conversation | Farmer একটি symptom বললে Agent instant medicine দেওয়ার বদলে structured questioning করবে—কতদিন, কত গাছে, কোন stage, recent rain, irrigation, previous spray, অন্য symptom আছে কি না। লক্ষ্য হলো ভুল diagnosis কমানো। | Agent hypothesis তৈরি → evidence চাইবে → alternatives narrow করবে → confidence বাড়াবে → তারপর action দেবে। দরকার: Diagnostic Reasoning, Probabilistic/Bayesian Logic, Domain Knowledge, Explainable AI, Question Strategy। Priority: MVP Core. |
| Safe Recommendation & Confidence System | Agriculture-এ ভুল advice-এর সরাসরি financial এবং biological impact আছে। তাই Agent high-confidence case-এ direct action দেবে, medium-confidence case-এ আরও evidence/test চাইবে, আর high-risk uncertain case human expert/lab-এ escalate করবে। | Agent internal confidence, severity, reversibility ও cost-of-error evaluate করবে। দরকার: Risk Classification, Confidence Calibration, Safety Guardrails, Escalation Rules, Human-in-the-loop workflow। Priority: MVP Core. |
| Dynamic Farming Timeline | Fixed calendar নয়; প্রতিটি plot/pond-এর live, context-aware timeline থাকবে। Planting, fertilizer, irrigation, spray, follow-up, harvest, stocking, feeding, pond check—সব weather ও current condition অনুযায়ী update হবে। | Agent crop/fish lifecycle, previous action, weather এবং field status combine করে next-best-action schedule তৈরি ও revise করবে। দরকার: Lifecycle Models, Scheduling Engine, Weather Data, Farm Memory, task dependency logic। Priority: MVP Core. |
| Best-Time Recommendation Engine | Agent শুধু 'কী করবেন' বলবে না—'কখন করবেন' বলবে। যেমন: "আজ spray দেবেন না; কাল বৃষ্টি। পরশু সকাল ৭–৯টার মধ্যে দিন।" Timing যেন farmer-এর labour availability, weather window ও crop stage-এর সাথে align করে। | Agent optimal action window calculate করবে এবং missed/changed condition হলে alternative window দেবে। দরকার: Weather Forecast, Crop Stage, Irrigation/Fertilizer/Pesticide Timing Knowledge, Optimization Engine। Priority: MVP Core. |
| Proactive Follow-up Agent | Question-answer শেষে relation শেষ হবে না। Treatment, fertilizer, pond intervention বা diagnosis-এর পর Agent নিজে follow-up করবে: "৩ দিন আগে যে সমস্যা ছিল এখন কেমন? একটা ছবি দেন।" Outcome না জানা পর্যন্ত case open থাকতে পারে। | Agent follow-up trigger, due date, outcome status ও unresolved case track করবে; farmer reply না দিলে contextual reminder দেবে। দরকার: Event Trigger Engine, Persistent Memory, Notification System, Outcome Tracking। Priority: MVP Core. |
| Proactive Risk Alert | Farmer সমস্যা বুঝে ওঠার আগেই Agent available data থেকে risk signal ধরবে—heavy rain, disease-friendly humidity, pond oxygen risk, crop stage sensitivity, market oversupply ইত্যাদি। Alert generic না হয়ে action-oriented হবে। | Agent external signal + farm context combine করে risk score করবে, affected asset identify করবে এবং preventive action দেবে। দরকার: Predictive Analytics, Weather-Disease Models, Risk Engine, Event Monitoring। Priority: Phase 2. |
| Weather-to-Decision Intelligence | Weather feature শুধু forecast দেখাবে না। Farmer-এর প্রশ্ন হবে: 'এই weather-এ আমার কী করা উচিত?' বৃষ্টি হলে spray delay, drainage open, pond overflow check, feeding adjust—এ ধরনের direct decision support দেবে। | Agent weather data-কে agronomy/aquaculture action rule ও farm history-এর সাথে translate করবে। দরকার: Weather API, Local Forecast Grid, Agronomy Rules, Aquaculture Rules, Decision Engine। Priority: MVP Core. |
| Soil Intelligence & Crop Suitability | Bangladesh-এর locality-wise reliable soil data এবং farmer-specific soil test/history একত্র করে কোন crop কোন plot-এ বেশি suitable তা explain করবে। Generic district suggestion নয়; specific plot-এর pH, drainage, fertility, irrigation, previous crop বিবেচনা করবে। | Agent soil/location/season/context match করে crop suitability rank করবে এবং evidence explain করবে। দরকার: Soil Database, GIS, Soil Science, Crop Suitability Model, soil test ingestion। Priority: Phase 2. |
| Crop Recommendation Engine | 'কোন crop-এর দাম বেশি' না; 'এই farmer-এর এই জমির জন্য কোন crop practical, profitable এবং manageable'—এই প্রশ্ন solve করবে। Profit, duration, input cost, risk, farmer skill ও market demand compare করবে। | Agent multi-factor crop ranking তৈরি করবে এবং scenario অনুযায়ী alternatives দেখাবে। দরকার: Agronomy, Yield Models, Soil/Climate Matching, Market Forecasting, Farm Economics, Risk Scoring। Priority: Phase 2. |
| Rice Intelligence Module | ধানের crop-stage, fertilizer, irrigation, pest, disease, lodging, weather risk, harvest timing ও plot-to-plot comparison-এর জন্য dedicated intelligence। এক farmer-এর ৩টি rice plot-ও আলাদা history/context-এ track হবে। | Agent rice-specific diagnosis, threshold, timing ও risk prediction করবে। দরকার: Rice Agronomy, Plant Pathology, Entomology/IPM, Soil, Weather, Harvest Science। Priority: MVP Domain. |
| Vegetable Intelligence Module | Eggplant, tomato এবং future-এ chilli, cucurbits, leafy vegetables ইত্যাদির frequent/dynamic problem management। Vegetable crop-এ pest, disease, irrigation, nutrient ও market timing বেশি frequent হওয়ায় high-value use case। | Agent situation-specific disease/pest/nutrient/irrigation recommendation ও short follow-up loop চালাবে। দরকার: Vegetable Agronomy, IPM, Pathology, Irrigation, Nutrient Management, Market Timing। Priority: MVP Domain. |
| Aquaculture Intelligence Module | Mixed fish ও Tilapia pond-এর water quality, fish behaviour, feeding, growth, stocking, disease, medicine, pond weather risk, harvest ও profitability track করবে। Farmer water colour বা fish movement-এর video/voice description দিয়েও help নিতে পারবে। | Agent DO/pH/ammonia/temperature context, feed/FCR, fish health, biomass ও weather analyse করবে। দরকার: Aquaculture, Fish Pathology, Water Chemistry, Feed/FCR Analytics, Stocking/Population Models। Priority: MVP / Phase 2. |
| Cross-Asset Intelligence | এক asset-এর activity অন্য asset-কে impact করলে Agent সম্পর্ক ধরবে। যেমন বেগুন ক্ষেতে pesticide → বৃষ্টি → drainage → পাশের pond → fish behaviour change। এই cross-farm linkage generic single-domain app-এর বড় সীমাবদ্ধতা কাটাবে। | Agent event timeline, farm map ও input records cross-reference করে causal risk detect করবে। দরকার: Farm Mapping, Cross-Asset Event Memory, Event Correlation, Toxicology Awareness, Multi-Agent Synthesis। Priority: Phase 2 — High Value. |
| Daily Farm Priority Engine | Farmer-এর শ্রমিক, সময় ও টাকা সীমিত হলে Agent বলবে কোন কাজ আগে করতে হবে। Example: ধানে fertilizer window, বেগুনে pest increase, tomato harvest ও pond oxygen problem একই দিনে হলে priority rank দেবে। | Agent urgency × irreversibility × financial exposure × weather window × labour requirement দিয়ে ranked action list দেবে। দরকার: Operations Research, Priority Scoring, Financial Risk, Multi-Agent Context। Priority: Phase 2. |
| 7-Day Farm Command Center | Farmer এক প্রশ্নে পুরো farm-এর next 7 days plan পাবে—কোন দিন কোন জমি/পুকুরে কী কাজ, কোনটা urgent, কোনটা delay করা যায়, কোন কাজ weather-dependent। Conversation-এর পাশাপাশি simple visual task cards থাকতে পারে। | Agent সব specialist task merge করে conflict resolve ও schedule optimize করবে; weather change হলে plan revise করবে। দরকার: Master Agent, Dynamic Scheduling, Task Dependency, Priority Engine, calendar/notification layer। Priority: Phase 2. |
| Market Price Intelligence | Local/nearby market-এর current ও historical price trend farmer-এর crop decision ও selling decision-এর context হবে। Gross price দেখানো নয়; farmer-এর বাস্তব বিক্রির cost ও market access বিবেচনা করবে। | Agent market price, local supply, demand trend ও transport context analyse করবে। দরকার: Market Data Feeds, Price Analytics, Location Mapping, Logistics Data। Priority: Phase 2. |
| Smart Selling-Time Recommendation | Harvest-ready produce আজ sell করবেন, কিছু অংশ sell করবেন, নাকি কয়েকদিন wait করবেন—এটা price trend, perishability, weather, storage এবং expected supply দেখে suggest করবে। | Agent Sell Now / Partial Sell / Wait scenario compare করে expected net outcome ও risk explain করবে। দরকার: Price Forecasting, Post-Harvest Science, Storage/Perishability Model, Market Risk Analytics। Priority: Phase 2. |
| Farm Financial Memory | Crop-wise শুধু বিক্রির টাকা নয়; seed, fertilizer, labour, irrigation, pesticide, feed, transport, lease, medicine ইত্যাদি cost capture হবে। Farmer voice-এ খরচ বললেও system record করবে। এর ফলে প্রকৃত net profit জানা যাবে। | Agent conversational expense extraction, category mapping ও season-wise P&L maintain করবে। দরকার: Farm Accounting, Expense Classification, Voice Data Extraction, Cost Ledger, Revenue Tracking। Priority: Phase 2. |
| Financial Crisis / Cash-flow Advisor | Farmer বললে "৪৫ দিনের মধ্যে ৮০ হাজার টাকা দরকার"—Agent তার সব crop, pond, upcoming harvest, feed/input obligation ও market condition দেখে realistic short-term cash plan তৈরি করবে। Premature harvest-এর loss বা crop switch-এর riskও দেখাবে। | Agent 30/45/60-day cash-flow projection, asset liquidation/harvest scenario ও short-cycle opportunity analyse করবে। দরকার: Cash-flow Modeling, Farm Portfolio Analysis, Harvest Forecasting, Market Data, Risk Constraints। Priority: Phase 2 — Strategic. |
| Risk-adjusted Profitability Advisor | Highest selling price নয়; farmer-এর জন্য এমন crop/strategy recommend করবে যেখানে expected net profit ভালো কিন্তু disease, weather, market volatility ও capital risk tolerable। | Agent expected revenue, total cost, yield uncertainty, market volatility ও biological risk combine করে risk-adjusted return rank করবে। দরকার: Yield Forecasting, Crop Economics, Risk Modeling, Scenario Analysis। Priority: Advanced. |
| Repeated Mistake Detection | Multiple season-এর decision history থেকে Agent farmer-এর recurring mistake ধরবে—late treatment, overfeeding, same pesticide repeated, overfertilization, late selling, repeated drainage neglect ইত্যাদি। উদ্দেশ্য farmer-কে blame করা নয়; pattern দেখিয়ে improve করা। | Agent decision→outcome timeline analyse করে recurring behaviour ও probable impact identify করবে। দরকার: Longitudinal Analytics, Pattern Recognition, Outcome Attribution, Explainable Feedback। Priority: Advanced. |
| Farmer Learning Through Action | Separate course/lesson নয়; real problem solve করার সময় farmer শিখবে। Agent recommendation-এর সাথে ছোট explanation দেবে—'এটা কেন', 'কী লক্ষণ দেখবেন', 'পরের বার কীভাবে আগে ধরবেন'। এতে knowledge transfer naturally হবে। | Agent farmer skill level অনুযায়ী explanation depth adjust করবে এবং repeated concept reinforce করবে। দরকার: Adaptive Education, Explainable AI, User Skill Modeling, Contextual Micro-learning। Priority: Phase 2. |
| Young / New Farmer Mode | যারা inherited land পেয়েছে বা agriculture-এ নতুন—তাদের জন্য guided mode। Agent প্রথমে field/pond assess করে crop plan, estimated budget, timeline, risk এবং daily guidance দেবে। লক্ষ্য: 'আমি কৃষি বুঝি না' barrier কমানো। | Agent beginner-friendly planning, stepwise guidance, prevention checklist ও learning feedback দেবে। দরকার: Farm Planning, Beginner Guidance, Education Model, Budget/Timeline Simulation। Priority: Phase 2 / Growth. |
| Human Expert Escalation | AI সবকিছু জানে এমন ভান করবে না। High-risk, low-confidence, unusual disease, chemical toxicity, severe fish mortality বা major financial decision-এর ক্ষেত্রে human agronomist/fisheries expert-এ escalation হবে। | Agent risk/confidence threshold detect করে case package তৈরি ও expert routing করবে। দরকার: Human-in-the-loop Workflow, Expert Network, Case Management, Risk Engine। Priority: MVP Safety Layer. |
| Auto Case Summary for Experts | Farmer-এর দীর্ঘ conversation, ছবি, treatment history, weather, crop stage ও timeline থেকে Agent এক page-এর structured case summary বানাবে—যাতে expert দ্রুত decision নিতে পারেন। | Agent relevant evidence select, chronology build, suspected causes, actions taken ও unresolved question summarize করবে। দরকার: Structured Summarization, Record Retrieval, Timeline Builder, Expert Handoff Schema। Priority: Phase 2. |
| Smart Notification System | Generic 'ফসল দেখুন' notification নয়। প্রতিটি alert actionable ও priority-aware হবে—কোন asset, কেন জরুরি, এখন কী করতে হবে, delay করলে কী risk। Low-value notification suppress করা হবে যাতে farmer alert fatigue-এ না পড়ে। | Agent urgency, due time, risk ও user behaviour অনুযায়ী notification rank/trigger করবে। দরকার: Event Engine, Priority Scoring, Notification Intelligence, User Attention Model। Priority: MVP. |
| Offline / Low-bandwidth Mode | Rural Bangladesh-এ unstable internet বিবেচনায় voice message queue, compressed image/video upload, cached task timeline, delayed sync, SMS/voice alert fallback থাকতে হবে। Core advice experience network-dependent হওয়া যাবে না। | Agent/network layer connectivity অনুযায়ী content compress, queue ও fallback channel select করবে। দরকার: Offline Sync, Compression, Store-and-forward, SMS/IVR Integration, resilient data sync। Priority: MVP / Phase 2. |
| Farmer Location & Geo-context | প্রতিটি plot/pond-এর approximate location Agent-এর weather, soil, flood, disease, market ও logistics intelligence improve করবে। Farmer-এর overall village/location এবং asset-level location দুইটাই relevant। | Agent geo-context দিয়ে local forecast, soil map, flood risk, nearby market এবং regional signal retrieve করবে। দরকার: GIS, Weather Grid, Soil Map, Flood Data, Local Market Geo-data। Priority: MVP Foundation. |
| Farm Risk Dashboard — Agent-led | Traditional complex dashboard primary UX হবে না। Agent conversation-এর পাশে simple supportive cards থাকবে: 'আজ ২টা জরুরি কাজ', 'Pond 1 high risk', '৩ দিন পর harvest'। Farmer চাইলে detail খুলবে। | Agent complex farm data concise visual priorities-তে synthesize করবে। দরকার: Information Synthesis, Risk Scoring, UX Personalization, Task/Alert Aggregation। Priority: Phase 2. |
| Government Agricultural Campaign Layer | Future B2G use case: government যদি onion/potato/other strategic crop production বাড়াতে চায়, generic mass campaign না করে soil/season/suitability অনুযায়ী relevant farmer-দের targeted opportunity explain করতে পারবে। Farmer benefit, risk ও support transparentভাবে দেখাতে হবে। | Agent national production goal ও farmer suitability match করবে; coercive messaging নয়, evidence-based recommendation দেবে। দরকার: National Demand Forecasting, GIS, Crop Suitability, Farmer Segmentation, Policy Data। Priority: Future / B2G. |
| National Demand–Supply Intelligence | Anonymized aggregated farm data থেকে কোন অঞ্চলে কী planting হচ্ছে, harvest কখন, সম্ভাব্য shortage/oversupply কোথায়—early national signal তৈরি হতে পারে। এটি farmer-first product-এর উপর future policy/market intelligence layer। | System large-scale production, crop-stage, risk ও market data aggregate করে supply forecast করবে। দরকার: Geospatial Analytics, Forecasting, Data Governance, Anonymization, National-scale Data Pipeline। Priority: Future Strategic Moat. |
| Government Incentive Matching | Subsidy, seed, insurance, loan, training বা strategic crop support থাকলে relevant farmer-কে তার farm suitability ও eligibility অনুযায়ী match করা যাবে। Farmer জানবে কেন সে eligible এবং কী benefit পাবে। | Agent policy rules + farmer profile + land/crop context match করবে। দরকার: Policy Data, Eligibility Engine, Farmer Profile, Consent & Verification Layer। Priority: Future. |
| Input / Treatment Record & Safety Log | কোন pesticide, medicine, fertilizer বা feed additive কখন, কত dose, কোন asset-এ ব্যবহার হয়েছে—voice বা Agent confirmation থেকে record হবে। ভবিষ্যতে duplicate dose, unsafe interval বা repeated chemical use detect করা যাবে। | Agent product/active ingredient normalize, date/dose record, interval check ও safety alert দেবে। দরকার: Agricultural Input Database, Chemical Safety Rules, Treatment Memory, Entity Normalization। Priority: MVP / Phase 2. |
| Outcome Tracking & Self-Learning Farm Model | প্রতিটি recommendation-এর পর outcome capture হবে—improved, unchanged, worsened, yield effect, cost impact, farmer feedback। আজকের intervention আগামী season-এর farm-specific learning হবে। | Agent treatment/action→follow-up→outcome chain maintain করবে এবং future recommendation-এ historical response ব্যবহার করবে। দরকার: Feedback Loop, Outcome Analytics, Long-term Memory, Recommendation Evaluation। Priority: MVP Core. |
